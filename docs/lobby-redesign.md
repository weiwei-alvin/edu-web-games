# 大廳改版：課堂遊戲索引

目標：減少制式生成頁面的視覺語彙，改為老師可投影、學生可快速選遊戲的目錄。
使用者已授權由開發者決定設計，直接實作，不另設設計核准關卡。

設計：暖灰紙色、深綠文字、少量磚紅重點；使用系統字體，以標題字級、細線與留白建立層次。大型藍色漸層、Emoji封面、浮動裝飾及膠囊標籤移除。桌面兩欄短清單，手機單欄；每款以固定編號與一個對應玩法的小型原生SVG示意辨識。頁首縮短，搜尋放在標題旁。

範圍：只改index.html、assets/lobby.js、assets/lobby.css；catalog及遊戲內容不動。全部/英語保留主導覽，無遊戲科目收進「其他科目」，不在頁尾重複陳列。

保留行為：window.CATALOG格式、#科目網址、搜尋與鍵盤快捷鍵、全部11款的原路徑、隨機導覽、返回時按鈕還原、深色模式、減少動態設定與鍵盤焦點。

實作與驗證順序：
1. 寫大廳瀏覽器驗收，確認舊版尚不符合新視覺結構。
2. 更換頁首、導覽與卡片呈現及響應樣式，不更改教材或題目。
3. Edge與Chrome驗證11個入口、搜尋/空結果/清除、全部與空科目切換、隨機導覽與返回、鍵盤操作、390/768/1440寬度及深色模式。
4. 截圖實際檢視桌面與手機，檢查溢出及文字可讀性；跑既有核心測試並確認遊戲檔案無差異。
5. 提交專用分支並建立PR至main，提供預覽；不沿用前次特定PR的合併授權。
