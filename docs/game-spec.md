# 國一英文單字遊戲開發規格

本文件依據課本第 108 頁字彙整理，規劃八款可使用 HTML、CSS、JavaScript 開發的網頁遊戲。遊戲依序涵蓋字義辨認、記憶檢索、拼字、語意分類、閱讀理解、位置描述、句型排序及綜合應用。

## 遊戲 1：單字配對大挑戰（Vocabulary Matching Challenge）

1. **學習對象**：國一學生，英文初級程度。
2. **學習目標**：辨認英文單字及中文意思，建立正確的字義連結。
3. **教學素材**：英文單字、中文翻譯；例句及其中文翻譯作為答題後補充。每局抽取 8–10 組。
4. **遊戲類型**：單字配對。
5. **操作方式**：滑鼠點擊兩張卡片，或拖曳英文卡片到中文卡片。
6. **遊戲規則**：英文與中文分列兩側，順序隨機；配對正確則鎖定，錯誤可重試；全部配對完成過關；重新開始時重新洗牌。
7. **回饋機制**：正確顯示綠色與「Correct!」；錯誤顯示紅色與「Try again!」；記錄完成組數、錯誤次數與首次答對率，結束後列出錯誤單字。
8. **技術條件**：HTML5、CSS3、JavaScript；支援點擊與拖曳；資料與程式分離；無須帳號或後端。

## 遊戲 2：翻牌記憶王（Vocabulary Memory Game）

1. **學習對象**：國一學生，英文初級程度。
2. **學習目標**：透過主動回憶英文與中文的對應關係，鞏固字義記憶。
3. **教學素材**：英文單字及中文翻譯，每局 4、6 或 8 組；例句作為補充。
4. **遊戲類型**：翻牌記憶配對。
5. **操作方式**：滑鼠點擊卡片翻面。
6. **遊戲規則**：卡片背面朝上隨機排列；每次翻兩張；配對成功保留正面，失敗則短暫顯示後翻回；完成所有配對過關；難度依卡片組數區分。
7. **回饋機制**：成功配對顯示正確提示；記錄翻牌次數、配對數與時間；結束後顯示成績及重新挑戰按鈕。
8. **技術條件**：HTML5、CSS3、JavaScript；翻牌動畫期間鎖定操作，避免同時翻開超過兩張未配對卡片；可離線執行。

## 遊戲 3：英文打字生存戰（Vocabulary Typing Challenge）

1. **學習對象**：國一學生，具備基本英文鍵盤輸入能力。
2. **學習目標**：根據中文意思獨立回憶並正確拼寫英文單字或片語。
3. **教學素材**：英文單字、中文翻譯、例句及片語，如 `expensive`、`smartphone`、`in front of`。
4. **遊戲類型**：打字闖關。
5. **操作方式**：鍵盤輸入，按 Enter 送出。
6. **遊戲規則**：每題顯示中文提示；輸入正確即進下一題；答錯可重試並在後續安排複習；每局 10 題；普通模式不限時，挑戰模式每題可設 15–30 秒。
7. **回饋機制**：答對顯示正確拼字；答錯先要求重試，錯兩次提供首字母，第三次仍錯則顯示答案並列入複習；統計首次答對率及提示使用情況。
8. **技術條件**：HTML5、CSS3、JavaScript；忽略大小寫及答案前後空白；片語需檢查字序；防止重複送出。

## 遊戲 4：單字分類工廠（Vocabulary Sorting Factory）

1. **學習對象**：國一學生，已初步學習本課單字。
2. **學習目標**：辨識單字的語意類別及基本詞性功能。
3. **教學素材**：依本課用法分類，例如 Places（`living room`、`bedroom`、`bathroom`、`kitchen`）、Objects（`smartphone`、`photo`、`blanket`、`tool`）、Actions（`choose`、`upload`、`wait`、`type`）、Adjectives（`quiet`、`expensive`、`soft`、`hard`）、Position Words（`behind`、`between`、`near`、`beside`）。
4. **遊戲類型**：拖曳分類。
5. **操作方式**：拖曳單字到分類區，或點選單字後選擇類別。
6. **遊戲規則**：每局顯示 4–5 類及 12–15 個單字；分類正確留在區域內，錯誤退回；全部完成過關；多詞性單字依教材用法設定可接受答案。
7. **回饋機制**：答對顯示中文與類別；答錯提示重新思考；顯示各類完成數，結束後整理錯誤分類。
8. **技術條件**：HTML5、CSS3、JavaScript；支援拖曳及點擊；分類資料可編輯；允許設定多個正確類別。

## 遊戲 5：House Detective 房屋偵探

1. **學習對象**：國一學生，已學習基本房間名稱與位置詞。
2. **學習目標**：閱讀簡短英文指令，辨認房間、物品及其位置。
3. **教學素材**：房間名稱（`living room`、`bedroom`、`bathroom`、`dining room`、`kitchen`）、物品（`smartphone`、`photo`、`blanket` 等）、位置詞（`near`、`beside`、`between`、`behind`、`in front of`、`next to`）；例句如 `Find the kitchen.`、`Click on the bedroom.`。
4. **遊戲類型**：圖片找物與閱讀解謎。
5. **操作方式**：滑鼠點擊房屋場景中的房間或物品。
6. **遊戲規則**：顯示房屋場景及英文任務；學生點選目標；答對進下一題，答錯可重試；每局 10 題；進階題加入位置描述。
7. **回饋機制**：答對使目標發光並顯示字義；答錯提示重讀；連錯兩次提供關鍵字提示；記錄首次答對率及錯誤題目。
8. **技術條件**：HTML5、CSS3、JavaScript；2D 場景與可點擊熱區；每題須有唯一且明確的目標；場景位置與答案資料一致。

## 遊戲 6：Room Designer 房間設計師

1. **學習對象**：國一學生，已學習位置介系詞與房間單字。
2. **學習目標**：理解並執行英文位置指令，辨識物品之間的空間關係。
3. **教學素材**：房間、物品及位置詞（`in front of`、`behind`、`between`、`next to`、`near`、`beside`、`inside`）；指令如 `Put the smartphone next to the bed.`。例句中的輔助物品詞彙須先提供圖像或說明。
4. **遊戲類型**：房間布置與位置解謎。
5. **操作方式**：滑鼠拖曳物品至指定位置。
6. **遊戲規則**：每關 3–5 個指令；依序移動物品，系統判定物品與參照物的相對位置；答對進下一題，答錯可調整；完成全部任務過關。
7. **回饋機制**：答對顯示「Well done!」並保留位置；答錯顯示「Check the position.」；連錯兩次標示參照物；關卡結束顯示各位置詞的表現。
8. **技術條件**：HTML5、CSS3、JavaScript；使用固定格線或區域判定位置，避免過度精細的像素比對；支援重設；避免物品遮擋互動區。

## 遊戲 7：Sentence Builder 句子建築師

1. **學習對象**：國一學生，已認識本課單字及基本句型。
2. **學習目標**：依語意排列英文單字，建立正確語序與句型概念。
3. **教學素材**：課本句型、英文例句與中文翻譯，例如 `The kitchen is near the bedroom.`、`I see a smartphone.`、`Please wait for me.`。
4. **遊戲類型**：句子排序。
5. **操作方式**：點擊或拖曳單字卡片排序，按 Check 檢查。
6. **遊戲規則**：每題顯示中文提示及打亂的英文詞卡；排列完整句子後送出；答對進下一題，答錯可重排；每局 8–10 題；難度依句長調整。
7. **回饋機制**：答對顯示完整句子及中文；答錯提示檢查語序；連錯兩次提供第一個單字；統計首次答對率及提示使用次數。
8. **技術條件**：HTML5、CSS3、JavaScript；支援點擊與拖曳排序、移回詞卡、答案檢查；標點由系統處理；可設定多種正確答案。

## 遊戲 8：Escape the House 密室逃脫

1. **學習對象**：國一學生，已完成本課單字與基本句型學習。
2. **學習目標**：綜合運用字義辨認、拼字、閱讀理解及句型知識完成解謎。
3. **教學素材**：本課已教單字、中文翻譯、位置詞、句型及例句，依教材設計謎題。
4. **遊戲類型**：任務式密室逃脫。
5. **操作方式**：滑鼠點擊、拖曳及鍵盤輸入。
6. **遊戲規則**：依序完成三關：第一關 Vocabulary Lock（單字配對取得鑰匙）、第二關 Location Puzzle（依位置提示尋找物品及密碼）、第三關 Sentence Code（句子排序或填空開啟出口）；可重試；普通模式不限時，另可提供計時模式。
7. **回饋機制**：完成關卡播放開鎖動畫；答錯提供逐步提示；顯示關卡進度；通關後顯示完成時間、首次答對率、提示次數及待複習題目。
8. **技術條件**：HTML5、CSS3、JavaScript；2D 場景及關卡切換；前端管理鑰匙、密碼、進度；答案由教材資料決定；支援重設，無須帳號或後端。

## 共通開發規格

| 項目 | 統一規格 |
|---|---|
| 開發技術 | HTML5、CSS3、JavaScript |
| 執行環境 | 電腦版 Chrome、Edge 等現代瀏覽器 |
| 交付形式 | 優先單一 HTML 檔案，必要素材可內嵌 |
| 教材資料 | 統一儲存英文、中文、例句、分類與可接受答案 |
| 介面語言 | 操作說明以繁體中文為主，練習內容以英文為主 |
| 操作方式 | 滑鼠點擊、拖曳；拼字遊戲使用鍵盤 |
| 音效 | 正確、錯誤及過關音效；提供靜音選項 |
| 題目順序 | 每次開始時隨機排列 |
| 錯誤處理 | 允許重試，避免答錯後無法繼續 |
| 學習紀錄 | 顯示首次答對率、錯誤題目及提示使用情況 |
| 資料儲存 | 預設只保留當次結果，不需學生帳號 |
| 教材替換 | 修改資料即可套用新課程 |
| 遊戲重置 | 提供重新開始按鈕，清除當局狀態 |
| 視覺設計 | 清晰字體與操作區域，避免過多動畫干擾 |

**教學評估原則**：遊戲 1–4 著重字義、記憶、拼字與分類；遊戲 5–7 著重理解及應用；遊戲 8 用於綜合複習。遊戲速度、翻牌次數與逃脫時間不能單獨代表英語能力進步，應以學生是否能在新題目中獨立正確作答作為主要判斷依據。
