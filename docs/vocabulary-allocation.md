# 八款英文單字遊戲單字分配表

依據前述八款遊戲設計，以下為建議的單字配置。不同遊戲可重複使用相同單字，以練習不同語言能力。

| 遊戲 | 學習單字與片語 | 主要學習能力 |
|---|---|---|
| **1. 單字配對大挑戰** | living room, bedroom, bathroom, dining room, kitchen, house, please, quiet, style, idea, tool, smartphone | 英文與中文配對 |
| **2. 翻牌記憶王** | step, upload, photo, choose, type, theme, wait, get, some, expensive, soft, hard | 回憶單字意思 |
| **3. 英文打字生存戰** | please, house, quiet, style, idea, get, some, tool, smartphone, expensive, question, blanket | 英文拼字 |
| **4. 單字分類工廠** | living room, bedroom, bathroom, dining room, kitchen, smartphone, photo, blanket, tool, choose, upload, wait, type, quiet, expensive, soft, hard | 語意分類與詞性 |
| **5. House Detective 房屋偵探** | living room, bedroom, bathroom, dining room, kitchen, house, smartphone, photo, blanket, near, beside, next to, between, behind, in front of | 場所、物品與位置辨認 |
| **6. Room Designer 房間設計師** | living room, bedroom, bathroom, dining room, kitchen, house, smartphone, photo, blanket, behind, in front of, between, next to, near, beside, inside | 位置介系詞應用 |
| **7. Sentence Builder 句子建築師** | please, wait, get, choose, type, upload, I see., Let's, in fact, with, question, idea, some, tool, near, beside, inside | 句型與語序 |
| **8. Escape the House 密室逃脫** | 本課全部單字與片語，包含前七款遊戲使用的字彙 | 綜合複習與應用 |

> **說明：** 本表為建議分配，並非每款遊戲只能使用所列字彙。遊戲 8 應以完整教材單字清單為題庫；前七款遊戲未列出的單字（如 around、world、ice）也應納入完整題庫，以免遺漏。
