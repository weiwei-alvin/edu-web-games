# 八款國一英文遊戲實作計畫

依據：game-spec.md、vocabulary-allocation.md 與使用者共通要求。
目標：八款完整可玩的靜態遊戲，保留既有三款遊戲和大廳。
架構：每款獨立 index.html；共用 assets/grade7 的教材、純函式、樣式及操作程式。共用素材是為資料與程式分離及一致維護的必要拆分，可直接離線開啟。
開發分支：feat/grade7-vocabulary-games，基準 16f3fc14ed20b51f28d2fe960c33de9506af8143。
使用者已要求直接執行，按下列順序於本聊天實作。

- [x] 1. 核心與教材：先測首次作答不被重試覆寫、提示排除獨立答對、正規化、固定格線位置判定，再建立教材資料區。
- [x] 2. 配對：8–10 組、兩列隨機、點選與拖曳、鎖定與錯詞例句回饋。
- [x] 3. 記憶：4/6/8 組、翻牌鎖、配對、次數與時間。
- [x] 4. 打字：10 題、普通/15–30秒挑戰、錯兩次首字母/第三次答案、錯題複習、防重送。
- [x] 5. 分類：12–15 詞、4–5 類、可複數答案、拖曳/點選、各類紀錄。
- [x] 6. 偵探：2D 熱區、10 題唯一目標、位置描述、兩錯提示。
- [x] 7. 設計師：每關3–5題、固定格線、拖放、保留位置、參照物提示、位置詞紀錄。
- [x] 8. 句子：8–10題、長度難度、點選/拖曳排序與移回、標點自動處理、兩錯首詞、多答案。
- [x] 9. 逃脫：配對鑰匙、場景密碼、句子出口三關，逐步提示、開鎖動畫、重設和成績。
- [x] 10. 大廳：只加入八筆 english 目錄，保持舊資料和導覽程式不變。
- [x] 11. 驗證：Node核心/資料測試、Chrome或Edge實際瀏覽器完成/錯答/重設/拖曳/計時及大廳回歸；記錄未驗證範圍。
- [x] 12. GitHub：檢查差異、提交、推送專用分支、PR至main，禁止自行合併。

共通：繁體中文操作、開始/遊戲/結束畫面、隨機順序、可重試、音效與靜音、只保留當局資料、不使用API或後端。
首次率：以每個原始題目/英文詞第一次實際提交為準；未答完的題目不冒稱答對；重試、提示後成功不提高首次獨立答對數。複習沿用原始紀錄。
注意檢查：重設時舊計時器失效；連擊不重複加分；同詞重複token獨立識別；空白輸入不計答錯；格線與場景資料同源。
教材限制：只有分配字彙及規格範例，沒有第108頁原文。中文、例句、位置題與排序題採清楚標示的自編補充；不宣稱完整課本覆蓋。around/world/ice也納入已列字彙的補充詞庫。
